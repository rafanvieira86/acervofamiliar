# Meu Acervo — versão 1

Sistema web de acervo pessoal em HTML, CSS e JavaScript puro.

## Como usar
1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Clique em **Adicionar ao acervo**.
4. Cadastre documentos, fotografias, vídeos, registros etc.
5. Use a pesquisa no topo.
6. Os registros desta versão ficam no `localStorage` do navegador.

## Estrutura
- `index.html` — aplicação principal
- `css/style.css` — interface
- `js/app.js` — lógica, cadastro, pesquisa e armazenamento

## Próxima evolução recomendada
Migrar os metadados para Firestore e os arquivos para Firebase Storage, acrescentando login, permissões, backup e compartilhamento.
